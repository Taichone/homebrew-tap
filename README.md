# homebrew-tap

Personal Homebrew tap.

## SimpleCut

Lightweight video editor for macOS (macOS 26 or later).

```sh
brew install --cask taichone/tap/simplecut
```

## Agents Monitor

Monitor Codex and Claude sessions from the macOS menu bar (macOS 14 or later).
The app is universal, Developer ID signed, and notarized by Apple.

```sh
brew install --cask taichone/tap/agents-monitor
brew update && brew upgrade --cask agents-monitor
```
