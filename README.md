# homebrew-tap

Personal Homebrew tap.

## SimpleCut

Lightweight video editor for macOS (macOS 26 or later).

```sh
brew install --cask taichone/tap/simplecut
```

The app is not notarized yet. If Gatekeeper blocks the first launch:

```sh
brew reinstall --cask --no-quarantine taichone/tap/simplecut
```
